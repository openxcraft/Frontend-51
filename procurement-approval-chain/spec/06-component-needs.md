## Layer-3 token additions

`request.line.total.*` (computed cell states), `chain.step.state.{queued|awaiting|approved|rejected|returned}.*` (icon+text+color triads per 05 status palette), `chain.step.delegation.*`, `envelope.bar.state.{within|approaching|over}.*` (honey/honey-deep/red ramp bindings), `envelope.bar.blocking.*` vs `envelope.bar.advisory.*`, `quote.row.lowest.*` / `quote.row.delta.*`, `quote.row.selected.*`, `seal.state.*` (the eight request states), `band.label.*` (threshold band chip states), `preview.rail.divergence.*` — all Layer 2 re-binds of the 05 palette; no raw values (token-architecture §1).

## Reused-with-twist

- **FilterChips**: band and status filters carry their amount intervals as accessible descriptions (P08's "accessible description of each predicate" made money-specific).
- **EmptyState**: S1 first-run sample-request card (interactive: loads the seeded request with quotes + chain so the routing-preview moment is experienceable pre-policy — CP non-happy path, P22); one action clears it forever.
- **JobRow**: export jobs carry artifact expiry countdown and the renewal action inline (async-contract §2 expired state surfaced where the capability is used, never in a settings graveyard).

## Icon-flip decisions (rtl-rules §2)

Delegation arrow and chain-flow chevrons flip in RTL (directional glyphs); the envelope, seal, quote-sheet, and band-step glyphs never flip (semantic anchors); the register's wait-age clock is a symmetric glyph; media/progress metaphors absent by design. Mixed-direction embedded tokens (request codes "PR-1041", currency "SAR", Latin vendor names inside Arabic chrome) render in bidi isolating containers — never ambient-direction sorting (rtl-rules §2, the top corruption source).
