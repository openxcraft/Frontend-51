## Layer-3 token additions

`register.row.zone.{steady|due-soon|overdue|lapsed}.*` (chip states — Layer 2 re-binds of Review Slate / Mashbooh Amber-Deep / Lapse Red / Haram Crimson per 05 contracts) · `ladder.rung.state.{upcoming|reached|cleared|missed}.*` (glyph+text states; cleared binds Halal Leaf) · `ingredient.status.{halal|haram|mashbooh|under-review}.*` (text-bearing variants only where 05 declares text-safe: haram/crimson, halal/leaf, under-review/slate, mashbooh uses amber-deep for text and amber for markers) · `suppliercert.state.{valid|expiring-soon|expired}.*` · `formulation.line.resolution.{resolved|needs-evidence|evidence-expired|unresolved-mashbooh|haram}.*` · `certificate.doc.surface.*` (overlay-document layer bindings) · `policy.version.draft.*` (Review Slate binding). No raw values anywhere (token-architecture §1); every status token resolves icon+text+color triplets, never color alone.

## Icon flip decisions (rtl-rules §2)

- **Flip in RTL**: stage-ladder direction glyphs (next/previous stage chevrons); ladder-timeline reading-direction arrow; "move line up/down" reorder glyphs; external-link arrow on evidence references; breadcrumb separators; pagination.
- **Never flip**: certificate-with-ribbon, leaf-in-flask, three-linked-nodes (traceability), question-in-diamond, gavel-outline, document-with-seal — semantic anchors, direction-free glyphs; clock glyph (time is not spatial); status diamonds (halal/haram domain anchors).
- **Metaphor-convention case recorded**: the ladder glyph itself is symmetric (rungs between rails) and never flips — a ladder reads the same in both directions, and the timeline's *order* (not glyph) carries direction.

## Deviations recorded

- Fully-rounded removable filter chips inside the density-B system: permitted exception for removable-chip semantics (P08), declared in 05 and here; all other radii in the B family.
- DiffView is used block-level (formulation lines), not character-level — formulation diffs are line-granular by entity design (07a); the shared primitive's contract is honored at block grain.
- QuotaMeter binds import/export job windows only. It renders nowhere else — there is no assist, no generation, no AI meter (declared non-AI, 00/08); metering the register itself would read as rationing record-keeping, which the product refuses on identity grounds.
