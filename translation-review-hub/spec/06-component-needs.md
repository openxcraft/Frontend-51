## Icon-flip decisions (rtl-rules §2, recorded per rule)

Columns/split (pane layout toggle): symmetric — never flips. Next/previous-segment chevrons: directional — flip. External-link arrow on findings rail: flips. Flag, alert-triangle, check-circle, clipboard, magnifier, globe: semantically anchored — never flip. Send (query submit): directional — flips. Consistency sibling link glyph: rendered as a paired-segment mark, symmetric — never flips.
