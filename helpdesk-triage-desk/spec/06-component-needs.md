## Icon-flip decisions (rtl-rules §2, recorded per rule)

Queue next/previous chevrons: directional — flip. Route/split glyph (routing): flow-directional — flips in RTL. External-link arrow (routing trace links): flips. Inbox, languages, layers, gauge, clock, flame, bell, check-circle, merge, archive, users, table, plug: semantically anchored or symmetric — never flip. The ticket-number mark "TK-" prefix is a Latin token — bidi-isolated, never reordered (rtl-rules §4).
