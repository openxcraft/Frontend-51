## Icon-flip decisions (rtl-rules §2, recorded per rule)

Calendar (week navigator): semantically anchored — never flips. Clock: never flips. Users/grid/columns (layout): symmetric — never flip. Next/previous-week chevrons: directional — flip. Arrow-left-right (swap provenance): symmetric in meaning (exchange) — never flips; the *log's* chronological ordering mirrors with the layout instead. Alert-triangle, alert-circle, check-circle, bell, settings, award: semantically anchored — never flip. Drag handles: direction-free geometry — never flip.
