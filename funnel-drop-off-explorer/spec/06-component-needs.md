## Reused-with-a-twist (documented deviations)

- **Sheet (docked, not modal)**: the seam dossier and its stack (anneal launcher, compare, narration, export) dock inline-end on the canvas rather than center-modaling — the cascade must stay visible during every interrogation (04 IA decision); focus discipline is identical (trap-free, return to trigger).
- **PasteImportSheet (sample import)**: paste textarea + column mapping preview; row-level validation errors quote the offending row; unknown events propose `proposed`-status dictionary entries (governance path) rather than dropping rows; the whole flow is the LOOP-5 manual-alternative PRIMARY path (08 N1).
- **DiffView (taxonomy rename)**: character-level name diff PLUS a usage-impact list (which funnels/steps reference the event) — the standard P16 diff extended with the reference graph the rename gates on (CP-4.3).
- **FilterChips (segment/analysis filters)**: chips carry the predicate-in-words described-by (P08) AND the origin provenance when filtering the workshop by run (the filter states which anneal produced what it shows — provenance discipline, 03 design note (a)).
