## Risk flags (LOOP-7 style, for binding-time owners)

- **N1 is the load-bearing need** and carries the freshest failure modes: a binding must declare its query-latency envelope (the 10 budgets are product promises — a source that cannot answer a seam query inside the budget degrades the canvas contract), its event-shape stability (a taxonomy version pins what a computation ran against — 07a ComputationBasis; a source that silently changes property enums between queries manufactures drift the UI would honestly but wrongly report), and its re-publish semantics (the 03 CP-2.5 live re-query discipline assumes append-only event arrival; a source that retracts events breaks the immutability of computation rows — the binding must surface retractions as freshness incidents, never as silent recomputation of pinned evidence).
- **N1 query-workload isolation**: funnels and anneals are interactive read paths (j/k seam navigation, one-key drill — 09); a binding that funnels analytics queries into a production transactional path is a capacity decision the OWNER makes at binding time, not a default the product assumes. The 10 budgets (metrics ≤ 1.5s p95; anneal ≤ 2s synchronous) are the declared envelope.
- **N4 privacy boundary is contract law** (07b rule 4 + ai-native-patterns §9): the model capability receives run METRICS only — never raw event rows, never user keys, never property values at user level. A binding that "improves" narration by feeding it user-level data violates the contract and the 09 privacy posture; the grant display must state the operation class ("composes narrative text from aggregated run metrics").
- **N4 does not grow**: no model anywhere else — the anneal is published math, the lint is deterministic rules, the taxonomy is human-governed (LOOP-10; 12 Q-9 records the refused instrumentation-keeping AI class). A binding-time temptation to "assist" taxonomy curation with a model is out of contract by construction.
- **N2 never promotes instant**: the ladder has zero instant classes at v1 (12 Q-13 — an exploration tool has no page-worthy emergencies); a channel binding must not add push urgency the product deliberately lacks. Digest batching semantics survive the binding.
- **N3 artifact expiry is a retention posture**: exported evidence carries a 7-day window by default; a destination binding with different retention must surface ITS window in the artifact record — silently indefinite retention of evidence packs is a policy decision, not plumbing (12 Q-12 adjacent).

## Consent semantics (per credential-contract)

- Credential-class surfaces are console-side only: event source binding, digest channel, artifact destination, narration capability, identity source — presented in capability language, kind-not-vendor ("يقرأ أحداث المنتج نيابة عن مساحة العمل" / "reads product events on behalf of the workspace"; "يؤلّف نص السرد من مقاييس التحليل المجمّعة" / "composes narrative text from aggregated run metrics"). The analyst canvas never renders credential kinds inline — sources surface as health/freshness chips (11 §G), which is the only source-visible state.
- Grant display precedes any save (credential-contract §4): each need's grant names the operation classes it unlocks (read events / send digests / deliver artifacts / compose narration / verify member identity) and nothing broader.
- **Data minimality is structural** (the 09 privacy posture): the contract's entity model carries pseudonymous user keys, declared taxonomy axes, and aggregated counts — there are no emails, phones, names, or free-form identifiers for ANY binding to leak (07b rule 8). The consent posture for N1 is thereby bounded by the adapter shape itself: the product asks for events, not people.
- Never-events (credential-contract §7): no event payloads or user keys in URLs, logs, or the narration path; the artifact channel carries composed evidence only; correlationIds never embed payload data.
