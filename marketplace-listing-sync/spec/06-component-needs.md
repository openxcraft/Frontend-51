## Shared patterns used (ux-patterns.md)

P01 (four empties — every surface's copy matrix in 11) · P02 (skeletons mirror table/rail geometry per direction) · P04 (delete ladder — deleteListing level-2 with publish history named) · P05 (⌘K palette, bilingual normalized search) · P06 (inline edit in mapping table + rule pack + master fields) · P07 (bulk select + action bar for publish/export/check) · P08 (filter chips + saved views on listings board + findings board) · P10 (autosave indicator in master editor) · P12 (import/check/publish/export Jobs surfaced) · P14 (quota meters for check runs/publish batches/assist suggestions — pre-operation surface) · P15 (trust checkpoint — suggestions are draft-by-default; publish promotes data only after human-selected batch) · P16 (diff views for master-edit propagation) · P17 (activity log — mapping saves, rule edits, publishes, acknowledgments) · P18 (keyboard-first grids everywhere) · P19 (virtualized findings/listings) · P20 (offline banner + queued master edits) · P21 (notification digest ladder for job completion + channel error arrivals) · P22 (first-run value checklist with the sample channel's planted blocker). P03/P13/P14-streaming not used: no optimistic mutations on listing state (readiness is authoritative — CONFLICT surfaces both versions), no streaming text (the assist produces structured suggestions, not streamed prose — the panel renders list rows, not token flow).
