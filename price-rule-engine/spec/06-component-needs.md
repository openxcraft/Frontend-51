## Icon-flip decisions (rtl-rules §2, recorded per rule)

- Chevrons (drawer disclosure, table pagination): navigation-direction class — **flip** in RTL.
- Send/submit arrow (proposal submit): directional — **flip**.
- arrow-down-to-line (cost floor): semantically anchored to the value axis (it depicts "down TO a floor line", not reading direction) — **never flips**; decision recorded in 05 §Icons.
- trending-up / trending-down (margin and price deltas): value-semantics glyphs (up is up in any script) — **never flip**.
- sigma, sliders, percent, banknote, calendar, triangle-alert, check-circle, clipboard, file-down, history, play (simulation run — media convention): symmetric or semantically anchored — **never flip**.
- External-link arrow (activity log references): **flips**.
