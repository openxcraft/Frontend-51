# 09 — Accessibility: price-rule-engine

SME-F pass · WCAG 2.2 AA floor (a11y-baseline), both directions (bilingual-en: chrome flips, both full citizens — 05 direction model), 1280px and 360px viewports, 200%/400% zoom. The product's structural a11y problems: **a virtualized before/after numeric grid** (the simulation row table — dense, sorted, filterable, 220+ rows at the buyer's scale), **per-row-direction bilingual cells** (an Arabic name inside an English table and the reverse), and **a gate that must refuse loudly** (proposal submission/approval — the refusal is the product's governance voice). Solved below as the row-grid focus contract, the per-row direction contract, and the assertive-gate schedule.

## Focus order & the per-row direction contract

Reading order per surface follows the workspace's active direction (bilingual-en default LTR; the full RTL flip re-renders every surface — Noura's chrome). The structural rule: **the names column renders each row's name at its own locale direction** (`dir="auto"` cells, rtl-rules §2) inside a table whose column order mirrors with the chrome; SKU tokens, prices, margins, and floors keep physical order stable in both directions (rtl-rules §4 — DA-7051 is DA-7051 and 96.14 is 96.14 in either chrome). Mixed-script fixtures are seeded (DA-7051's nameAr "مبخرة كهربائية SlimLine" — Latin brand inside Arabic, bidi-isolated at render). The row table's focus model is strictly one focusable row cell-set per row (roving tabindex on the row, cells reachable with ←/→ in physical column order); a focused row is announced by its identity (SKU + direction + margin delta), never by color or glyph alone (05 decision palette: judgment is icon + signed numerals + color, always).

## Per-surface WCAG 2.2 AA checklist

- **S6 simulation workspace (the hard one)**: 400% zoom reflow with worst-case Arabic strings ("مستشارو التدقيق والحوكمة" — rtl-rules §5) in the names column; the table collapses to row cards below 768px and at zoom overflow (skill row 71 — 06), each card keeping its own direction; truncation breaks at word boundaries only; targets ≥24×24 (clamp chips, filter chips, drawer disclosure, pagination); the clamp is **icon + text + color** ("Floor 96.14" with the arrow-down-to-line glyph — never amber alone, 05); margin judgment is green/red **with signed tabular numerals** (the numerals are the data — color-blind access is structural, not accommodated); price direction renders in ink (uncolored) so direction and judgment never merge channels (05); the sticky header never covers the focused row (2.4.11).
- **S2 rule editor**: labels persist above fields — never placeholder-as-label (a11y-baseline §5); FormulaPanel updates ≤120ms in a reserved height (06 — no layout shift while typing); window fields carry the Hijri/Gregorian cross-reference as hint text (P24, active system explicit); priority collisions announce the other rule's name; Escape restores (P06) with focus returning to the last-edited field.
- **S4 item detail**: the cost timeline mirrors in RTL with nodes in chronological (not visual) focus order; back-dated insertions announce their position ("effective 1 Oct, recorded 2 Oct"); the manual price path requires its note at the field (assertive above); correction badges link to the corrected record.
- **S5 composer**: quota shown before running (P14); cost snapshot date picker exposes the dual-calendar disclosure; scope pickers list categories with bilingual labels at own direction.
- **S7 proposals + gate**: exclusion dialog requires the reason (empty reason cannot submit — the dialog's primary button stays disabled with an explanatory live line, not a mystery); blocker rows are keyboard-traversable links (above); the approval seal block renders as a definition table (actor, timestamp, counts) readable by SR; post-approval the frozen proposal announces "snapshot — later edits do not reach this record".
- **S8 jobs**: honest determinate progress as text; cancel within one interaction; partial results named (async-contract §4).
- **S9 settings**: capability consent in capability language (kind, not vendor — credential-contract §2); market/VAT edits are versioned fields with conflict surfacing; no cognitive-function tests anywhere (3.3.8 — paste is never blocked); 3.3.7 redundant entry: the composer recalls the last scope and rule mode per session.
- **S1/S10 lists**: virtualization preserves focus (P19); filtered states declare themselves (P08); the four empties distinct per P01 (11); activity rows carry actor-action-target with timestamps announced on focus.
- **Salem's mobile read mode (CP-3.6)**: the summary header is the surface — blended margin per market, counts, snapshot date — as a definition table; row cards are read-only; no pinch-zoom-dependent affordances.

## RTL/LTR verification matrix (per surface, both chrome directions)

For each of S1–S10, both chrome directions: pure-Arabic render · pure-English render · mixed strings (Latin brand inside Arabic name — seeded DA-7051 is the fixture; a Latin SKU inside an Arabic row on every table) · numeral rendering under the Western policy inside Arabic chrome (prices, margins, floors, VAT rates — never mixed systems mid-sentence, copy-voice §1.7) · embedded Latin/numeric tokens in RTL · tables/grids mirrored (catalog, row table, proposal table — column order mirrors; alignment rules held; tabular figures keep physical order) · forms (rule editor label/error placement on the correct inline edge — the error sits inline-end of its field in RTL) · truncation at 320px container with worst-case strings · 400% zoom reflow · bidi isolation on user-generated content (catalog paste can carry anything — `dir="auto"` on names, isolate marks on interpolations). **Content-direction fixtures run both ways**: an Arabic item name inside English chrome and an English name inside Arabic chrome (the names column guarantees both cases on every table that shows items); drawer disclosure chevrons and pagination flip (navigation class) while arrow-down-to-line, trending glyphs, sigma, play, and the clamp stamp never flip (06 §icon-flip — value-semantics anchors).

## Reduced-motion contract (motion-language §5)

Route crossfades → hard cuts; "The Clamp Settles" → instant strike-through + amber chip + the identical polite announcement (perceivability by construction, 05); FormulaDrawer opens instantly with the focus trap and return intact; row focus highlight remains (a <80ms color change at 2.4.13 strength — focus indication is exempt from motion budgets and never the only signal); job progress is text-determinate regardless of motion preference; nothing staggers, nothing bounces, nothing celebrates. The announcement schedule above is the reduced-motion equivalent of every animated transition — all state changes remain perceivable with motion disabled.
