## Deterministic computation rules (the whole engine — non-AI, specified exactly)

1. **Cost snapshot resolution** (03 CP-3 edge): for each scoped item at `costSnapshotAsOf`, the active cost record is the latest with `effectiveFrom ≤ snapshot` (date-only comparison), else the earliest record, else none. Zero records → the row is counted `skippedNoCost`, returned only under the `noCost: true` filter, never simulated with an invented cost. `landedCost` = Σcomponents — computed, never stored twice.
2. **Canonical arithmetic and margins** (03 CP-1.4): all money is integer minor units at the market's `currencyMinorDigits`. **roundHalfUp(a/b)** for positive integers = ⌊(2a + b) / 2b⌋ (half rounds up; negative results round half away from zero — margins can be negative, prices never are). `marginPermille = roundHalfUp((net − landed) × 1000 / net)` (away from zero). Workspace floors: `floor = roundHalfUp(landed × (1000 + markupPermille) / 1000)`.
3. **Rule matching and action semantics** (07a RuleAction): a rule is **considered** iff status = `active` (active-set mode: every active rule; selected mode: exactly the named rules, any status — rehearsing a draft is legitimate, 02 Noura). Window check: `validFrom ≤ simDate ≤ validTo` (missing bounds unbounded); window-excluded considered rules land in `rulesNotApplied` with reason `window` — visible, never silently dropped. Conditions AND-compose: `category` (item's categoryId ∈ list), `channel`, `market`, `price-band` (min ≤ currentNet ≤ max), `margin-band` (min ≤ marginPermille ≤ max — only evaluable on rows with cost; no-cost rows were skipped at rule 1). Matched rules evaluate in **ascending priority** (strict total order — ties were rejected at save); within a rule, actions apply in declared order: **REBASE** `set-markup`: `net = roundHalfUp(landed × (1000 + m) / 1000)`; **REBASE** `set-target-margin`: `net = roundHalfUp(landed × 1000 / (1000 − g))` (g ≥ 1000 → VALIDATION at authoring; g ≥ marginPermille sanity is the author's, not the engine's); **COMPOUND** `adjust-price`: `net = roundHalfUp(net × (1000 + d) / 1000)` (d negative = markdown); **floor-at-markup**: registers a floor `roundHalfUp(landed × (1000 + f) / 1000)`; **ending-round**: registers its mode (the last registered ending wins — later-priority rules override earlier endings).
4. **Ending conventions and the floor clamp — the final pipeline** (07a invariant; 03 CP-3.4): after all actions produce `rawRulePrice`, the registered ending applies, then the clamp is LAST. Endings, exactly: `none` identity · `whole-unit` **truncate toward zero to the whole major unit** (the customer-favoring whole-riyal convention — 84.50 → 84.00, 99.03 → 99.00; the trace shows the dropped fraction, and the clamp guarantees the floor afterward) · `charm-9` **round UP to the nearest value whose minor part is all 9s** (84.50 → 84.99 at 2 digits; 84.500 → 84.999 at 3) · `nearest-half` **roundHalfUp to the nearest 0.5 major units** (84.75 → 85.00, 84.60 → 84.50). **activeFloor** = max(workspace default floor, all registered rule floors, item `floorOverride.absoluteFloorNet`) — the winner's `source` is recorded (`workspace-default | rule | item-override`); an item override "wins by max" only when higher (03 CP-1 edge). **Clamp**: `floorApplied = (roundedPrice < activeFloor)`; `proposedNet = max(roundedPrice, activeFloor)`; `endingBrokenByFloor = floorApplied AND rawRulePrice ≥ activeFloor` (the ending introduced the breach — reachable fixture: `set-markup 85‰` on DA-7024's landed 89.02 gives raw 96.59 → whole-unit 96.00 < floor 96.14 → final 96.14, flagged plum; `set-markup 80‰` + `nearest-half` gives raw 71.17 = floor on DA-7051-class rows → rounded 71.00 → flagged). **Floor-only pass (no matched rules — 03 non-happy)**: no ending step; `proposedNet = max(currentNetPrice, activeFloor)`; the row's trace is cost → floor check → final. Every clamped-to-derived-floor row lands at margin 74‰ (8/108) — the floor's own margin, visible arithmetic.
5. **VAT display rounding** (06 VatDisplayPair): `displayPrice = roundHalfUp(net × (1000 + vatRatePermille) / 1000)` at the market's minor digits — 599.00 AED → 628.95 (01 [31]); simulations record `vatRatesUsed` and workspace market edits never retro-mutate written simulations (07b rule 9).
6. **Margin preview aggregation**: per market only, never cross-currency: `blendedMarginPermille = roundHalfUp(Σ(net − landed) × 1000 / Σnet)` over that market's simulated rows (catalog-weighted — no sales data at v1, LOOP-10); after-figures use `proposedNet`; `netRevenueDelta = Σ(proposed − current)` in that market's minor units; direction counts (up/down/flat) compare proposed vs current net.
7. **Determinism and immutability (the oracle)**: identical (catalog state, cost records effective at snapshot, pinned rule versions, scope, snapshot date) → byte-identical rows and summary; simulations are immutable snapshots (re-running creates a new id); `getSimulation` re-reads recompute identically; every result carries `mode: 'deterministic'`.
8. **Seeded clock and cadences**: the clock starts 2026-11-12T09:30+03:00 and advances only on declared actions at fixed cadences (import 40ms per 10 rows; cost-sheet 40ms per 10 rows; simulation 40ms per 10 items; export 80ms per format); timestamps in jobs/activity/records derive from this clock only — **no Date.now anywhere**.

- `importCatalog` (paste) — row grammar `sku | nameEn | nameAr? | category | market | channel | net | cost? | floor?`; invalid rows are named and skipped, valid rows land (partial policy, async-contract §4); a market code the workspace lacks → VALIDATION naming the row and the allowed codes; unknown categories are created flat on the fly; duplicate SKU → the row UPDATES the existing item (idempotent upsert, recorded) — the paste path over the sample; rows without the cost column import as-is and count `skippedNoCost`; import-created cost records take `effectiveFrom` = job clock date, `supplierCost` = pasted cost (single-component; full components via `saveCostRecord`); pacing determinate "n of total".

- `listCatalogItems` — filters (category/market/channel/belowFloor/hasCost/marginBand), normalized bilingual search over sku + both names (rtl-rules §4 pipeline, disclosed), sorts; cursor pages ≤ 100; derived fields (`costBasis`, `marginPermille`, `belowFloor`, `displayPrice`) compute at read per rules 1–5 — never stored as second opinions.
