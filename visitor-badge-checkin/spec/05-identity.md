## Typography (P06 — Almarai + Inter)

- **Arabic: Almarai** (real weights 300/400/700/800 — rtl-rules §3 discipline). Body 400 at 17px+ (kiosk body 20px+); secondary 300 for large display supports; **700 for desk headings and the single H1; 800 ExtraBold reserved for the kiosk confirmation screen and the badge visitor name** — the two moments where a person's own arrival must be unmissable at arm's length. This display-weight strategy (300/800 at the extremes) is the P06 co-use differentiation (below).
- **Latin: Inter** (400/500/600/700). 500 for table headers and board labels; 600 for numerals-dense cells (tabular figures on times/codes); 700 for desk H1 in Latin chrome. Inter is P06's own Latin half — no third family at T3; codes and phone numbers render at tabular-figure settings within the pairing.
- Line-height: Arabic 1.6 / Latin 1.5 (kiosk Arabic 1.7 — arm's-length reading); tracking 0 for Arabic everywhere (token-level, rtl-rules §3); no synthetic bold on missing weights (Almarai has no 500/600 — re-bind 400/700).
- **Numerals: Western** (ledger row; data/record surface per design-language-map §7): times, dates, codes, counts, and phone numbers render 0-9 in both directions; Arabic-Indic never appears in system chrome. Kiosk date/time formats follow the workspace locale (Gregorian ISO storage; Hijri display is a presentation concern this product does not surface at v1 — visit windows are operational, dual-calendar is P24's calendar-family concern; recorded in 12 Q-12).

**bilingual-ar** (proposed, LOOP-6 pending confirmation): Arabic-first RTL is the default for BOTH modes — the kiosk greets in Arabic with the language switch one tap away (research digest sources 18, 20: bilingual RTL reception is the regional expectation; sources 38–42: the lobby is a hospitality surface and the guest's language leads), and the desk defaults to the workspace locale with English as full citizen. Verification matrix in 09, both directions full-citizen.

## Shape, elevation, iconography, motion

- **Density B (standard, 6–10px)**: cards 8px, table rows 6px, kiosk panels 10px. Fully-rounded exception ONLY for the removable filter chips (P08) and the kiosk language toggle (a pill is the one control a standing visitor must never miss) — declared deviation, recorded here.
- **Elevation: flat-line**: hairline sky-tinted borders carry all structure; today-board columns separate by border weight and the canvas→raised surface step, zero shadows. The badge preview is the "deepest" object on any screen and achieves it by border weight + the band strip alone — a printed artifact must look flat because it IS flat.
- **Icons: line-2** (standard 2px outline set): arrival glyph (door-with-arrow), host glyph (person-with-pulse-dot), badge glyph (rectangle-with-code), code glyph (hash-mark), void glyph (slash-through-rectangle), sweep glyph (broom-line). Directional arrows flip in RTL; badge/host/sweep glyphs never flip (semantic anchors — rtl-rules §2, decisions recorded in 06).
- **Motion: minimal** (motion-language §1): opacity-only transitions ≤120ms; position changes instant with crossfade; route changes hard cuts at this tier's discipline. **Exactly one signature micro-interaction (T3 rule)**: **"The Arrival Settle"** — when check-in commits, the visitor's name on the kiosk confirmation screen settles once (opacity 0→1, 120ms, no scale, no travel) while the host-notification chip changes state in the same frame; reduced-motion: both changes render instantly with the polite announcement carrying the same information (motion never carries information alone — a11y-baseline §4). Nothing else moves: no badge flip, no board reflow animation, no confetti at checkout.
