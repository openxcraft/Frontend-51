## Layer-3 token additions

`tree.node.expansion.*` (chevron state marks), `code.block.settle.*` (the signature settle's two-step opacity states), `duty.chip.{standard|exempt|protected|specific}.*` (text vs UI-ink variants per 05 computed contracts), `note.status.{current|superseded|withdrawn}.*`, `change.kind.{added|retired|description-changed|rate-changed|code-split}.*`, `savedcode.status.{candidate|desk-verified|flagged}.*`, `gap.mark.*` (the Arabic-rendering-absent mark) — all Layer 2 re-binds of the 05 palette; no raw values above Layer 1 (token-architecture §1/§3).

## Reused-with-twist

- **Breadcrumbs**: persist the drill path AND the originating surface ("Search: 'جبن' → results" as the first crumb) — context preservation is the drill-down discipline's core (05 integration record).
- **DiffView**: edition-level rows (code + change-kind + old→new values), not character diffs — schedule amendments are line-level facts.
- **QuotaMeter**: assist window only; deterministic search and browse render NO meter (unmetered by design — the degradation floor must not read as rationed; 07c behavior note).
- **EmptyState**: S1 first-run offers the seeded sample list (interactive: loads three settled classifications so the save-link-export loop is experienceable pre-import — CP non-happy path, P22).

## Icon-flip decisions (rtl-rules §2)

Flip in RTL: tree expansion chevrons, breadcrumb separators, pagination arrows, "open note" directional arrow, edition "previous/next" pair arrows. Never flip: magnifier (search), bookmark-pin (lists), stacked sheets (notes), gear (settings), lattice tree glyph, code blocks (always LTR-isolated content), duty-structure glyphs (percent, unit-scale — semantically anchored). The gap mark (missing Arabic rendering) is a constructed dashed-bracket glyph, direction-free by design.
