## Deterministic computation rules (fixed tables — the core heuristics, not vibes)

- **Search normalization (norm-v1, disclosed in-product)**: strip tashkeel; أ/إ/آ → ا; ة → ه; ى → ي; code-shaped input (≥2 consecutive digits) → strip all non-digits and treat as code-prefix query. Arabic and English tokens both index; the matched field is reported per hit.
- **Search ranking (exact rule)**: (1) exact full-code match first; (2) code-prefix matches, longest prefix first; (3) description hits ranked by matched-term count desc, tie broken by code lexicographic asc; page cap 50. Regression fixtures: "دجاج مجمد" and "frozen chicken" both rank 0207.14 first via the ar/en token tables; "شاشه" (taa-marbouta misspelling of شاشة) still matches 8524 via the ة→ه rule; "أرز" and "ارز" match identically via the alef rule; "02.07" matches code 0207 (dot stripping).
- **Assist mapping table (fixed; mode 'assist')**: bilingual keyword → candidate code + score + matched terms: chicken/دجاج/poultry/دواجن → 0207 (0.91; +frozen/مجمد narrows to 0207.14, 0.94) · cheese/جبن → 0406 (0.88) · rice/أرز → 1006 (0.90; +basmati/بسمتي → 1006.30, 0.93) · smartphone/هاتف ذكي → 8517.13 (0.94) · charger/شاحن → 8504.40 (0.92) · LED lamp/مصباح LED → 8539.50 (0.95) · drone/طائرة بدون طيار → 8806 (0.96) · display/شاشة → 8524 (0.89) · 3D printer/طابعة ثلاثية الأبعاد → 8485 (0.95) · T-shirt/تيشيرت → 6109 (0.90) · biscuit/بسكويت → 1905 (0.87).
