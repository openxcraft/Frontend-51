# 02 — User Research: content-remix-studio

SME-B pass · Paraphrased sentiment only (marked).

## Persona 1 — Khaled, Newsletter Author (primary)
**Role**: writes a bilingual Arabic/English newsletter on regional tech; 8K subscribers; repurposes each issue into a thread + 2 posts by hand every week.
**JTBD**: "When I publish an issue, I want the thread and posts drafted from it within the hour, in MY voice, so distribution doesn't eat my writing day."
**Triggers**: distribution exhaustion (he ships less because remixing costs an evening); a thread that read "translated" bombed.
**Objections**: "automation tools flatten my voice"; "I won't babysit black-box output" (receipts answer this); price must be solo-tier.
**Onboarding motive**: run one recipe on his best-performing issue and compare against last week's hand-made thread.
**Verbatim (paraphrase, creator sentiment)**: "I write once; the internet wants it five ways. The four other ways eat my week."

## Persona 2 — Yasmin, Course Creator
**Role**: produces bilingual course modules; needs module teasers, community announcements, and email nudges per module.
**JTBD**: "When a module ships, I want launch-derivative pack from one source, so marketing the course doesn't outgrow making it."
**Triggers**: launch weeks where marketing ate production time; inconsistent messaging across derivative formats.
**Objections**: recipe definitions must be editable (her launch structure is hers); receipts matter for messaging consistency audits.
**Verbatim (paraphrase)**: "Every format needs the same promise said its own way — by hand that's a day per module."

## Persona 3 — Boutigue agency owner (Samar)
**Role**: 2-person content boutique; remixes client long-form into platform packs monthly.
**JTBD**: "When I deliver a content pack, I want recipes per client so every month's derivatives are structurally identical, so my deliverable is a system, not vibes."
**Triggers**: client noticed structural drift between months; margin lost to manual remixing.
**Objections**: client separation (workspace-per-client); export formats must match client platforms' habits.
