# 06 — Component Needs: kyc-onboarding-flow

SME-C/D pass · Shared primitives consumed (from the foundation) + the product's invented components. Each invented component declares its a11y and motion obligations explicitly (flagship discipline: nothing invented without a keyboard path, a screen-reader story, and a reduced-motion behavior). Pattern links to _shared/ux-patterns.md are named per component; token additions follow token-architecture §3.

## Shared primitives consumed

Button (verb-labeled, B-radius 6px controls, ≥44px targets on the applicant shell), TextField/Select/DateTime (autocomplete tokens declared on personal-data fields — a11y-baseline §5), Menu, Dialog/Sheet (focus-trapped; the dossier is a drawer, decisions are sheets), Tabs (dossier layer navigation within one region), Toast (P21 ladder, 3–5s), Tooltip (console only), Skeleton (P02, RTL-mirrored geometry), EmptyState (P01 four empties), FilterChips + SavedViews (P08, URL-serialized), ActivityLog renderer (P17), JobRow/JobDetail (async-contract §7), NotificationInbox primitives (P21), CommandPalette (P05, bilingual normalized search), OfflineBanner + queued-write rows (P20), KeyboardGrid table primitives (P18 — the console queue), DiffView primitives (P16 — template version history).

## Reused-with-a-twist (documented deviations)

- **Drawer (task detail)**: in-place expansion over the queue (not a route — 04 IA decision); focus moves in on open and returns to the row on close; the dossier + composer stack is two levels max.
- **QueueTable (console)**: P18 keyboard grid (j/k + arrows; range select absent — decisions are never bulk); row deadlines tick at 1Hz with tabular numerals and zero layout shift.
- **FlowDesignerBoard (program)**: an ordered step list with drag-reordering AND a keyboard move alternative (2.5.7 — Alt+↑/↓ per step, recorded in 09); threshold fields are numeric inputs with the spec-proposed default provenance chip ("قيم افتراضية مقترحة" / "spec-proposed defaults" — 12 Q-6); publish carries the in-flight versioning declaration (CP-6.2).
- **TemplatePreviewSheet**: renders the applicant view per-locale with bidi isolation visible in an inspect mode (P23-adjacent discipline; channel-abstract — no channel branding, 08).
- **DateTimeSheet (session policy editor)**: idle/absolute/resume-window fields as duration steppers (Descope's idle/absolute/rolling taxonomy as the field structure, 01 §4.3).

## Icon metaphor ledger (rtl-rules §2 record)

Flip in RTL: next/previous chevrons (step navigation), the retake-rotate glyph (directional redo metaphor), external-link arrows (support/dispute paths), the spine's forward-progress arrowhead. Never flip: clock (deadlines), camera (capture), document/id-card (steps), check-circle (gate pass), alert-triangle (mismatch/critical), shield (data-use), layers (dossier), bookmark (resume — the physical bookmark metaphor is direction-neutral), scale (program/policy), signature/attest glyph (seal — physical object metaphor), upload tray (semantically anchored). Justification: flipped glyphs are directional metaphors; unflipped are physical-object or semantically anchored metaphors — recorded per rtl-rules §2 requirement. Icon construction: line-2, 24px grid, 2px stroke, currentColor (05).
