# Portfolio Foundation
The shared foundation project for the 50 standalone frontend products in this repository.

- PLAN.md — deep understanding + professional build plan
- FULL_VERIFICATION.md — final verified results (build 50/50, typecheck 50/50, audit 0 problems)
- tools/ — the spec-driven generator (tools/generate.mjs), build-all, audit and typecheck scripts + the shared app template
- shared-foundation/ + spec-shared/ — the 10-file shared design foundation (tokens, RTL, a11y, patterns, async/credential contracts)
- spec-index.md / spec-flagship.md / spec-verification.md — portfolio roster, flagship selection, spec verification
- SPEC_DEFECTS.md — defects found in the specs' own TypeScript, with fixes (corrected in generated code only)
