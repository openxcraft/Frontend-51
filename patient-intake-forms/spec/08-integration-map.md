# 08 — Integration Map: patient-intake-forms

Declared **conditionally-AI** (ai-native-patterns §1): exactly one operation consults a capability — `normalizeSymptomText`'s assist layer — and the product remains fully functional with every capability unbound (the 00 success signals run the full builder→fill→review→export loop against the mock's `assistCapabilityBound: false` default, the audited v1 state). Architecture speaks only in abstract capabilities; UI copy says kind, not vendor (credential-contract §2). No EHR write exists anywhere in the contract — the intake package handoff is the boundary (LOOP-10, named honestly in-product per 11).

## Capability binding gates (LOOP-7 posture — evaluated at binding time, not now)

- **N1 match-quality gate**: a fixed bilingual evaluation set (colloquial phrases from the seeded variants + planted unmatched fixtures) must pass a published precision floor before N1 ships active; every assist output renders with confidence displayed as a hint, never a promise, and the P15 confirm step stays non-negotiable regardless of measured precision. Failure/latency/quota of N1 degrades to the dictionary identically to the unbound state (degradation map).
- **N2 delivery fidelity**: package integrity at destination — the intake record is a clinical handoff artifact; corruption or partial delivery surfaces as typed errors with per-format retry, never silent truncation.
- **N3 address hygiene + link privacy**: consent-scoped recipients only; messages carry the opaque token and the clinic's bilingual name, never symptom data, never answer content (data-minimization per credential-contract §7).
- **N4 provenance honesty**: imported terms carry their source provenance chip; bulk import that would overwrite clinic-authored entries requires an explicit merge decision at import time (the `دوار` deprecation-merge precedent, 07c).

## Degradation map (ai-native-patterns §8 — the conditionally-AI ladder, stated per surface)

| Surface | All capabilities unbound (default v1 state) | Capability failing mid-session |
|---|---|---|
| Builder, bilingual publish gate, vocabulary manager | **Full function** — authoring, versioning, the gate, term CRUD are local rules (07c) | Full function — no capability touches these surfaces |
| Patient fill surface + SymptomInputField | **Full function** — dictionary chips render (exact/normalized); assist chips simply never appear; the field's help text never promised them | If N1 fails mid-typing: the reserved suggestion region shows the honest "no further suggestions" state; typing continues uninterrupted (keystroke budget unaffected — the assist path is async by construction, 10) |
| Normalization panel (review console) | **Full function** — exact/normalized/unmatched entries; unmatched text maps by staff hand; the "assist" mode column renders its honest empty (11) | In-flight assist proposals that already landed stay pending-confirmation (they are typed entries, not live queries); new ones stop arriving |
| Submissions queue, review gate, urgent flags, export | **Full function** — flags derive from the deterministic rule (07c rule 4); the review gate is local | Full function — only the assist-mode supply pauses |
| Fill invitations (N3) | Printed QR / kiosk / read-aloud link — the front desk's native channels | Channel failure → typed error on the invitation surface; QR/kiosk unaffected |
| Export & handoff (N2) | Download + print (the default path) | Channel failure → per-format retry + manual download of what delivered |

Quota ladder (ai-native-patterns §5): the metered platform operations are export packages and vocabulary imports (P14, `getUsage`); **normalization calls are never metered** — the typed `'unmetered'` literal in 07b is the contract-level guarantee that a clinic's vocabulary work is never taxed by match volume (12 Q-3). There is no AI rung to fall from below the dictionary: the ladder's floor IS the product.

## Risk flags for the owner

- N1 is the highest-visibility binding and the lowest-risk one (drafts are confirm-gated by type — 07b rule 1); its absence caps match rate on colloquial phrasing, not any workflow (the 07c A/B oracle measures exactly this delta on the seeded fixtures).
- N2 is the highest-leverage binding (the download-and-upload walk is the daily tax); its absence is honestly survivable — the printed record is a real clinical habit, not a compromise.
- The EHR boundary (no record writes at v1, in EITHER direction) is a LOOP-10 exclusion, not an integration gap: a live record write would re-open 00's exclusions discussion and require the LOOP-4 process with the owner first (12 Q-20 records the forward declaration posture — none declared).
