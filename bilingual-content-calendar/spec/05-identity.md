## Color
- **Primary — "Taba Spring"**: oklch(0.62 0.13 148) ≈ #2FA36B (planning green — growth/arrangement semantics for a scheduling surface; distinct from the flagship's ink authority). Used for structure, active modes, moment markers.
- **Accent — "Ramadan Lantern Gold"**: oklch(0.80 0.14 88) ≈ #EDBE4F for moments and season highlights; used sparingly (the moments library is where the brand shows joy).
- **Surfaces**: paper-light default oklch(0.97 0.006 120) ≈ #F4F7F2 with soft-lift elevation; dark theme re-binds Layer 2 (grid on oklch(0.24 0.02 150)).
- **Status**: parity both-ready (spring deep), one-missing (amber), diverged (critical oklch(0.55 0.19 25)); all pairs meet declared contrast contracts; parity never color-alone — icon + text (09).
- Rationale: buyer lives in a grid all day → calm mid-luminance green prevents the fatigue of high-chroma chrome; joy reserved for moments (the differentiating surface).

## Typography (P13 — Baloo Bhaijaan 2 + Plus Jakarta Sans)
- **Arabic: Baloo Bhaijaan 2** (700 headers/month labels, 500 for moment titles; body/UI 400 is handled by the Latin pairing's Arabic companion role — see exception below). Rounded, warm, calendar-friendly.
- **Latin: Plus Jakarta Sans** (400/500/600/700) — contemporary rounded-grotesque, pairs tonally.
- **Body-text exception (documented)**: Baloo Bhaijaan 2 is a display-weighted family; long planning notes render in **Almarai 400** (utility-neutral) with the pairing preserved for identity surfaces (headers, chips, moments). Rule: "identity text = pairing; note text = Almarai". Contrast pairs re-declared for the combination.
- Line-height 1.6 Arabic / 1.5 Latin; tracking 0 for Arabic (token rule); numerals Western (dates render Hijri day names in Arabic where locale=ar).

## Direction model
**bilingual-ar** (proposed): grid direction follows workspace locale; variant panes always render their own direction (P23); Hijri header renders in both locales. Verification matrix in 09.

## Shape, elevation, icon, motion
- **Radius D (pill/20+)**: slot chips, status pills, moment badges — friendly planning surface; large soft shapes read as arrangement tokens, not documents.
- **Elevation: soft-lift**: slots lift gently off the grid; dragging a slot raises it one shadow step (with keyboard alternative — 09).
- **Icons: filled-rounded**: friendly solids for channels/moments; no thin-line fragility in a dense grid.
- **Motion: crisp** (motion-language §1): 100–180ms ease-out; slot drag = live pickup; month/season transition = single 160ms crossfade with grid settle; NO overshoot (timing tool, precision feel). Signature micro-interaction (T2 obligation): **moment placement** — a moment chip drops into the horizon and its timing pattern ripples across the affected week (160ms stagger, ≤5 elements); reduced-motion: pattern highlights appear instantly with a summary announcement.
