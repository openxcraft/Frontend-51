- **Documented reading exception (LOOP-9 resolution; house precedents: arabic-copy-studio 05, zakat-calculation-suite 05, khatt-type-playground 05)**: text meant to be READ at body/table sizes — the ranked board's dense cells, shift-record tables, forms, labels, buttons, chips, help copy — renders in **Readex Pro (400/500/600, both scripts from one family)** as a supporting role, explicitly NOT an identity-pairing claim (P18's ledger allocation is untouched). Single rule: **display = P18; reading = Readex Pro.** Reason recorded honestly: Lalezar and Bebas Neue are display temperaments; asking them to carry a 13px bilingual record table is a legibility defect, not a brand victory. Readex Pro is chosen for bilingual-native single-family behavior — one face covering both scripts at data densities (bilingual-en surface, 02).
- Line-height: Arabic 1.6 / Latin 1.5 (record tables honor tashkeel headroom when Arabic store names carry marks); headings ≥1.4. Tracking: 0 for Arabic everywhere (token-level, rtl-rules §3) — Lalezar's connected display forms make this non-negotiable. Numerals: **Western** (ledger row; analytics/data surface per design-language-map §7) — scores, deltas, SAR amounts, week numbers all 0-9, tabular-figure settings in Readex Pro where the implementation supports it (the ui-ux-pro-max mono-for-data instinct adopted as a RULE, not a third family).

## Shape, elevation, iconography, motion

- **Density B (standard, 6–10px)**: KPI tiles 10px (plates), ranked-board rows 6px, chips fully-rounded exception ONLY for removable filter/basis chips (P08 — declared deviation, recorded here), store cards 8px.
- **Elevation: soft-lift**: diffuse ambient shadow steps carry the hierarchy — canvas → card → plate; no hard borders, no stacked occlusion. The ranked board's rows lift one soft step on focus/hover (affordance discovery only); the KPI plate is the highest soft-lift surface (the signage metaphor: numbers on a raised plate).
- **Icons: duotone** (two-tone constructed set): store glyph = awning-front duotone; shift classes = sun-rise / sun-high / sun-low / moon duotone marks; comp badge = double-tick outline-over-fill; coverage = partial-plate; season = crescent-over-square; annotation = tag-over-line. No sparkle glyphs anywhere (non-AI declaration, ai-native-patterns §1). RTL: directional glyphs (drill chevrons, week navigation arrows) flip; semantic anchors (sun/moon marks, comp badge) never flip (06 records per glyph).
- **Motion: energetic** (motion-language §1): 150–250ms, standard ease with a single controlled overshoot (≤8% travel) reserved for success moments (run complete, artifact ready) — never for errors, never on data changes. Ranked-board rows settle in place on re-run (no spin-in, no race — the comparison grammar, 13); the shift-lens grid re-renders ≤150ms crossfade on KPI switch; cell tint changes pair with the text delta always (motion never carries information alone, a11y-baseline §4). Route changes crossfade ≤180ms. Reduced-motion: hard cuts + announcements; the overshoot collapses to a state chip (motion-language §5).
