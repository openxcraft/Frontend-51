## Layer-3 token additions

`objective.card.unreported.*` (the "—" state), `objective.card.warning.{unstaffed|orphaned}.*`, `pair.editor.parity.*` (in-sync / edited-since / length-far-apart), `lint.finding.{task-verb|soft-verb|length|parity}.*`, `assist.panel.{streaming|partial|provenance}.*`, `checkin.form.{draft|grace|overdue}.*`, `confidence.dial.{1..5}.*`, `coverage.grid.cell.{ontime|ingrace|overdue|missing|draft}.*`, `grade.sheet.{formula|aspirational|excluded}.*`, `cascade.edge.*` and `cascade.lane.*` — all Layer 2 re-binds of the 05 palette; no raw values anywhere (token-architecture §1).

## Reused-with-twist

- **DiffView**: check-in corrections show before/after values and confidence side by side with the recomputed progress delta — numeric diffs, not character diffs.
- **ConfirmLadder**: archive actions are P04 level-2 (single item, irreversible-in-effect, consequence named with counts); cadence change is level-2 with the migration semantics named; no level-3 (type-to-confirm) exists at v1 — no bulk-destructive container operations are in the contract.
- **QuotaMeter**: assist draft runs only; the deterministic editor, lint, check-ins, and grading render NO meter (unlimited by design — the floor must never read as rationed, the house pattern from seo-brief-builder).

## Icon-flip decisions (rtl-rules §2)

Flipped in RTL: cascade drill-in chevrons, board lane flow arrows, "next period" stepper, external-link arrow. Never flipped (semantic anchors): flag (objective), target-with-notch (key result), pulse-line (check-in), lattice (alignment), dial (confidence), clock-with-dot (period), trash (archive), magnifier (search). The pen-tip assist glyph is direction-free; its label string carries the direction. Decisions recorded per rtl-rules §2 (metaphor-anchored glyphs keep their orientation in both directions).
