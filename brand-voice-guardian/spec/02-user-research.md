# 02 — User Research: brand-voice-guardian

SME-B pass · Paraphrased sentiment only (marked).

## Persona 1 — Omar-type Brand Manager (primary; same archetype as studio's Omar — governance-side)
**Role**: brand manager, UAE e-commerce group; owns voice across 40 writers/agencies.
**JTBD**: "When copy from anywhere in the org reaches publish, I want machine-flagged drift against my profile before my eyes touch it, so I review judgment calls only."
**Triggers**: terminology drift in live email flows; off-register Arabic in a regional campaign; audit asking for proof of review.
**Objections**: "governance tools cost a project-team and a quarter"; "will it understand my register?" (01 gap #1 is his exact pain); "reports must survive an audit, not a demo".
**Onboarding motive**: paste last week's shipped copy and see real findings in the first ten minutes.
**Verbatim (paraphrase)**: "Consistency is the whole job; speed is negotiable." (same archetype sentiment as studio's Omar record)

## Persona 2 — Salma, Agency QA Editor
**Role**: final-check editor at a Rabat agency; runs every deliverable through checks before client delivery.
**JTBD**: "When a bilingual deliverable lands on my desk at 5pm, I want a five-minute pass that catches banned terms and register slips, so the client never catches them first."
**Triggers**: a client flagged a competitor name in copy; register slipped in translated sections.
**Objections**: check must be fast and shareable (report link, not file ping-pong); false positives would burn her trust permanently.
**Verbatim (paraphrase, QA-editor sentiment)**: "One false positive and I stop believing the tool."

## Persona 3 — Tariq, Compliance-minded Comms Lead (regulated industry)
**Role**: comms lead at a financial services firm; copy carries regulatory phrasing rules.
**JTBD**: "When regulated claims appear in copy, I want banned-phrase enforcement with an audit trail, so compliance sign-off is evidence, not memory."
**Triggers**: regulator inquiry requiring proof of review process; a banned superlative slipped through agencies.
**Objections**: he needs exportable, timestamped, actor-attributed reports (P17 discipline); false negatives on mixed-language text would be unacceptable.

## Voice derivation (SME-J)
Guardian voice: precise-auditor — respectful, never scolding. Findings copy describes the text, never the writer ("This line slipped below declared formality" — not "you wrote informally"). Arabic فصحى بيضاء with fixed terminology (تدقيق=governance pass، نتيجة=finding، انحراف=drift). English professional-neutral.
