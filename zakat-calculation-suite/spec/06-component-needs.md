# 06 — Component Needs: zakat-calculation-suite

SME-C/E pass · 11 invented components. Each carries purpose, key states, a11y obligations (a11y-baseline), pattern links to _shared/ux-patterns, Layer-3 token additions (token-architecture §3), and RTL icon-flip decisions (rtl-rules §2). All money renders as canonical Western-digit storage with display formatting above the adapter (07a); components never parse numerals differently by locale.

## C-01 — ItemIntakeForm (category-first progressive form)

**Purpose**: the LOOP-5 primary path — one item at a time, category → fields the category needs (P09): cash → amount; gold-silver → weight/purity-context note + jewelry flag; livestock → heads by class; crops → kg + irrigation; receivables → amount + recoverability; liability → amount + due-context. Mid-hawl flag appears only for hawl-bound categories. **Key states**: clean · field-level validation (on-blur) · category-reshaped (fields re-disclose without losing entered values) · submitting · added-confirmation (inline row reveal) · locked-case refusal (VALIDATION with successor path, 11). **A11y**: labels persistent, programmatic required, error summary focuses first error; the category picker is a radiogroup with arrow navigation. **Patterns**: P09, P11 (recalls last-used category per case). **Layer-3 tokens**: `itemintake.category.radiogroup.gap`, `itemintake.field.stack.space`. **Icons**: category glyphs (line-1.5: coin, ingot, crate, camel/cattle/sheep, wheat, envelope) — symmetric, never flip.

## C-02 — ItemTable (the evidence grid)

**Purpose**: the officer's working surface — filterable, sortable, inline-editable item rows with void-with-reason. **Key states**: loading skeleton (P02, direction-mirrored) · empty variants (first-run / filtered / no-access per P01) · inline-edit cell (P06: Escape restores, Tab commits-advances) · voided rows (struck-through, reason on demand, never hidden) · stale-edit CONFLICT banner with both values · virtualized beyond 200 rows (P19: focus never moves for scroll). **A11y**: P18 grid grammar — arrow navigation, range selection, F2/Enter to edit; row-count announced on region entry; each row's amount cell exposes its currency. **Patterns**: P01, P06, P07, P08, P18, P19. **Layer-3 tokens**: `itemtable.row.height.compact`, `itemtable.void.strike.color`, `itemtable.cell.amount.font-tabular`. **Icons**: chevrons flip RTL; the void glyph (strike) symmetric.

## C-03 — NisabGauge (threshold arithmetic surface)

**Purpose**: renders the basket-vs-threshold relation: net base, threshold value (grams × pinned per-gram), above/below verdict, signed distance when below — the two numbers the product exists to relate (05 signature interaction lives here). **Key states**: un-pinned (VALIDATION state naming the metal + manual path, links to C-05) · computing · above-nisab (jade verdict) · below-nisab (slate verdict + distance figure — information, never error) · re-pinned (note: re-pin + re-run produces a NEW result version). **A11y**: the verdict is text + polite announcement when the result lands; the gauge geometry is decorative duplication — every figure is in text (motion never carries the verdict alone); distance announced with sign words ("أقل من النصاب بـ" / "below the threshold by"). **Patterns**: P13-adjacent announcement discipline (no per-token noise); P22 (sample case teaches it first). **Layer-3 tokens**: `gauge.threshold.arc.weight`, `gauge.verdict.chip.background`, `gauge.distance.marker.color`. **Icons**: mizan (balance) — symmetric, never flips.

## C-04 — TraceLedger (the derivation spine)

**Purpose**: the audit answer — one line per classify/value/aggregate/deduct/threshold/rate/round step, each naming rule id + source chip + bilingual narrative + item link; the recessed bed of the calculation surface (layered-depth sunken stratum, 05). **Key states**: rendering cascade (≤5-line groups, ≤60ms stagger — text complete without motion) · line-expanded (rule details, source note, both language sides) · rule-chip → profile rule side-panel · mid-hawl flag visible on its line · excluded-item lines (excludedReason stated plainly, e.g. jewelry within uruf). **A11y**: it is a table semantically (step, rule, narrative, amount); every line's narrative is complete text; announcement only on completion ("تم اشتقاق النتيجة في ٢٣ سطرًا" / "Result derived in 23 lines"). **Patterns**: P17 spirit (accountability surface); P16 for result-version diffs. **Layer-3 tokens**: `trace.line.rule-chip.border`, `trace.bed.background` (sunken), `trace.line.expand.gap`. **Icons**: step glyphs symmetric; source-chip external-link arrow flips RTL.

## C-05 — NisabReferenceBoard (entered references & pinning)

**Purpose**: lists entered reference values per metal (per-gram, as-of, source note, active), enters new ones (append-only), and pins a pair to a case. **Key states**: first-run empty (teaches the manual path — no feed ever required) · entry form (amount + as-of + source note) · superseded entries (visible history, deactivated, never edited) · pinned-to-case badge · currency-mismatch flag at pin time (different currency than the case → documented-decision prompt, never silent FX) · locked-case pin refusal (successor path). **A11y**: money inputs labeled with currency; pin action announces both metals. **Patterns**: P01, P10-adjacent save states, P03 (no optimistic pin — pins are authoritative writes). **Layer-3 tokens**: `refboard.pin.badge.background`, `refboard.superseded.opacity`. **Icons**: pin — semantically anchored, never flips.

## C-06 — ComparisonMatrix (profiles × categories)

**Purpose**: the signature flow's surface — same case, 2–5 approved profiles; per-cell dues; divergence markers with rule pair + bilingual reason; "no divergence" stated plainly where schools agree; in-kind dues shown as kind names, never monetized silently. **Key states**: profile-picker (approved only; mixed-status set refused with VALIDATION) · computing (per-profile pinned calculations) · divergence row (amber marker border, amber.deep text reason, rule-pair side-by-side from C-07) · in-kind cell (kind names like "٣ من الإبل ثنايا" / "3 four-year-old she-camels") · identical-results state · retired-profile-after-generation (snapshot stays valid — version pins noted on the cell). **A11y**: matrix is a table with row/col headers; divergence cells carry `aria-describedby` to their reason; cell values announced with profile name. **Patterns**: P01, P16 (cross-result comparison), P07 for bulk export selection. **Layer-3 tokens**: `matrix.divergence.marker.border`, `matrix.cell.amount.font-tabular`, `matrix.header.school-chip.background`. **Icons**: git-branch (comparison) — directional, flips RTL.

## C-07 — RuleCard (methodology rule with source)

**Purpose**: renders one CategoryRules entry: rate/threshold/treatment + source notes (citation or verify-flag) + version context — the unit the shariah authority actually reviews. **Key states**: approved (in force) · draft (re-versioned edit) · retired (listed history, unusable for new cases) · verify-flagged (amber "seeded-default — authority must verify" treatment, distinct from digest-cited) · side-by-side (comparison divergence pairing). **A11y**: verify-flag is icon+text, never color alone; source links open in a side panel preserving place. **Patterns**: P15 spirit (rules are authoritative state — the owner's approval is the checkpoint); P01. **Layer-3 tokens**: `rulecard.verifyflag.chip.border`, `rulecard.source.link.color`. **Icons**: book-ribbon (source) symmetric; chain-link flips.

## C-08 — ReviewPacket (submit → decision → lock)

**Purpose**: the certification state machine's surface: evidence summary + trace + pins + history for the reviewer; approve/return decisions with notes; lock action; successor spawn with reason. **Key states**: draft → in-review (frozen for review) → approved → locked (jade-deep seal band, white 11.11:1) · return-to-draft (reason required, officer must act) · successor-spawned (chain link visible) · gate refusals (reviewer lock-without-approval → VALIDATION naming the decision gate; officer edit on in-review → typed refusal). **A11y**: decision buttons are verbs with objects ("Approve case" / "اعتمد الحالة"); attestation-style focus order across the packet (a11y-baseline §7 legal/audit obligation); timestamps announced with the action. **Patterns**: P04 ladder for the lock (Level 2: names consequence — freezes items, profile, pins), P17 activity on every transition. **Layer-3 tokens**: `packet.seal.band.background`, `packet.decision.note.field.width`. **Icons**: stamp (lock) symmetric — the seal never flips.

## C-09 — ArtifactList (export jobs & artifacts)

**Purpose**: jobs with honest progress (rows imported, artifacts minted), cancel/retry, artifact rows with format, expiry window, renew action, regenerable flag. **Key states**: queued (honest waiting) · running determinate ("الصف ٤ من ١٢" / "row 4 of 12") · awaiting-input (ambiguous import row links to its decision) · succeeded (artifact linked) · failed (typed error + scoped retry) · cancelled · expired (NOT_FOUND + regenerate). **A11y**: progress text not percentages alone (async-contract §3); completion delivered in-context first (P12); polite announcements. **Patterns**: P12, P21 ladder. **Layer-3 tokens**: `artifact.expiry.chip.background`, `job.progress.text.width`. **Icons**: document-with-lines symmetric; download arrow flips RTL.

## C-10 — UsageMeter (window discipline)

**Purpose**: import/export window consumption with the in-product policy note that calculations are never metered (07b rule 9 — determinism is not rationed). **Key states**: nominal (calm, persistent) · 80% warn (amber.ui border + amber.deep text, P14) · exhausted (RATE_LIMIT with reset time + manual paths) · read-failure degrade ("last known"). **A11y**: meter value in text; warn announced politely once. **Patterns**: P14. **Layer-3 tokens**: `usage.warn.border`, `usage.note.text.color` (text.secondary). **Icons**: gauge symmetric.

## C-11 — SampleCaseBadge (P22 value moment)

**Purpose**: marks the seeded fully-worked trading-company case in S1 — one click opens the trace, the nisab gate, and the comparison moment before real data exists; clears in one action; never returns; never mixes into exports unless explicitly included (07c). **Key states**: offered (first-run) · opened · cleared (the offer was made — recorded). **A11y**: badge is text+icon; clearing is a P04 Level-2 confirm naming what clears. **Patterns**: P22; P01 first-run. **Layer-3 tokens**: `sample.badge.border`, `sample.badge.label.color`. **Icons: sparkle forbidden** — the badge uses the mizan glyph; nothing implies AI affordances.
