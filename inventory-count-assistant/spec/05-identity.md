## Shape, elevation, iconography, motion

- **Density B (standard, 6–10px)**: count-sheet rows 6px, policy cards 8px, catalog rows 6px. Declared deviation: fully-rounded chips ONLY where the semantic is a removable filter/class chip (P08) — same recorded exception class as the seo sibling; every other radius stays in the B family.
- **Elevation: flat-line**: hairline moss-tinted borders carry all structure; the variance ledger reads as the "deepest" surface by border weight alone; zero shadows anywhere (the stockroom lights are fluorescent enough).
- **Icons: outline-geometric** (constructed-grid outline set): item = box lattice outline, scan = corner-brackets-with-bar, variance = delta-triangle outline (sign carried by text, never by icon flip), recount = two-arrow cycle outline, tolerance = bracket-ruler, blind mode = rectangle-outline with diagonal tally-slash (masked quantity — the product's own glyph), IRA = gauge outline, zone = shelf-lines. No sparkle glyphs, no smart affordances (declared non-AI — ai-native-patterns §1).
- **Motion: crisp** (motion-language §1): 100–180ms, standard ease-out, zero overshoot ever. Route changes crossfade ≤180ms; count entries settle in place ≤120ms; variance rows never spin in. Success moments: state chip + polite announcement, no animation-carried meaning. Reduced-motion: hard cuts + announcements — identical perceivability by construction.
- **Signature micro-interaction (exactly one, T3) — "The Ledger Reveal"**: when the manager ends counting in a blind session, the masked tally column of the count sheet resolves into the variance ledger — one 140ms crossfade on the column as a whole (not per-row), signed deltas and tolerance brackets drawn as static geometry behind the fade, and a polite announcement naming the counts ("14 items, 3 variances outside tolerance"). The reveal is the product's judgment moment; the motion does no work the text does not repeat. Reduced-motion: the column swaps instantly with the same announcement. No other surface may borrow this treatment.
