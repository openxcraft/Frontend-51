## Original proposals

- **The Gate Needle (signature micro-interaction)**: reading-speed as a physical needle gauge per cue; edits move the needle in real time; clearing the gate settles it with the 140ms decelerate + announcement (05 motion). The QC flow becomes: G-key through gates, watch needles settle. Reduced-motion: numeric state swap with same announcements.
- **Break Workbench as two-futures view**: when two legal breaks exist, the workbench shows both line layouts side-by-side (with the linguistic note from 11-E) — the editor picks a future, not a parameter. Both options carry identical keyboard paths.
- **Spec-sheet-as-deliverable posture**: the burn-in spec rendered as a designed document (the export IS a designed artifact — Mariam hands clients something that looks governed, not a settings dump).
