## Reused-with-twist

- **DiffView**: burn-in spec revisions (placement/policy block-level compare, direction-aware — P16) and caption-style version compare.
- **EmptyState**: board first-run embeds the value checklist (P22) + sample-episode action (interactive empty, not dead text).
- **JobRow**: import/export rows with determinate per-segment / per-clip counts; partial-failure rows name the failed clip and offer scoped retry alone (async-contract §4).
- **QuotaMeter**: render minutes only — selection, search, heuristics, and specs are never metered (non-AI declaration; the meter governs the real variable cost).
- **ConfirmLadder**: level 3 (type-to-confirm naming the episode source) for `deleteEpisodeSource` — a container delete cascading clips and artifact history; level 1 undo for clip deletes; level 2 for batch export with warnings outstanding.

## Icon decisions recorded (rtl-rules §2 obligation)

Flip in RTL: cut-bracket direction glyphs, next/previous segment arrows, drawer chevrons, export-arrow, external-link arrow, the "extend selection" chevrons. Never flip: playback controls (play/pause/seek/volume), magnifier, refresh, trash, the safe-zone frame (geometry, not direction), the segment-bar glyph (symmetric). Real-world-metaphor call: the clip glyph is a bracketed cut (reading-order anchored → flips); the caption bubble is speech-shaped but symmetric (never flips); the playhead is a vertical line (direction-free geometry).
