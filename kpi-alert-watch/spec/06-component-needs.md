## Layer-3 token additions

`detection.row.severity.{critical|warning|digest|acknowledged|snoozed}.*` (icon+text+color states per 05 contracts), `detection.row.arrival.*` (The Explained Arrival states incl. reduced-motion), `explanation.card.pair.*` (EN/AR block states, number-slot emphasis), `explanation.card.provenance.*` (template/assist chips), `series.band.{warning|critical|baseline|season}.*` (chart zone tokens — flat zones, numbered edges), `watch.card.policy-prose.*`, `backtest.preview.count.*`, `digest.doc.{header|section|season-note|quiet-day}.*`, `season.strip.{active|queued|past}.*`, `snooze.control.*` — all Layer 2 re-binds of the 05 palette; no raw values (token-architecture §1).

## Reused-with-twist

- **FilterChips**: status/tier/feed/date chips carry an accessible description of each predicate (P08); fully-rounded radius is the declared deviation for removable-chip semantics only (05).
- **EmptyState**: S1 first-run sample feed (interactive: loads the seeded series + sample watch so the backtest and explanation moments are experienceable before real data — CP-1 non-happy path, P22).
- **QuotaMeter**: narration-assist window ONLY; the deterministic engines render NO meter anywhere (unmetered by design — the degradation floor must not read as rationed; the 08 map's honesty).
- **JobRow**: evaluation/ingestion/sync/delivery rows show determinate progress in units (points, feeds, digests) — never fake percentages (async-contract §3).

## Deviations recorded

- Fully-rounded filter chips inside radius-B system: permitted exception for removable-chip semantics (P08), declared in 05; all other radii in the B family.
- Icon flip decisions (rtl-rules §2): queue-advance chevrons and "open detection" directional glyphs flip in RTL; the bell, flag, calendar, check, x, and pulse-line glyphs are semantically anchored and NEVER flip; the season-strip timeline mirrors by layout, not by glyph flipping.
- The page-class banner is the one surface permitted critical-red as a rule line at full width; every other critical use is a mark + text (the ≤5% discipline, 05).
